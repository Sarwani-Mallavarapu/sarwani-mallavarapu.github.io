Billing and Collection System

Customer billing, on-line payment and collection systems, from data clean-up to operation.

GECE has implemented New Customer Billing and Collection system at 3 locations. The activities undertaken are:

  1. Supply & installation of software for customer billing & on-line payment
  2. Establishing Billing datacenter with heavy duty printers
  3. cleaning Existing Customer Billing database
  4. Migrating data to new database structure.
  5. Conducting Factory Acceptance test
  6. Implementing Pilot Project and conducting Site Acceptance Test
  7. Rolling out the system across utility and Running for 3 months
  8. Providing Annual maintenance support for 3 to 5 years.
