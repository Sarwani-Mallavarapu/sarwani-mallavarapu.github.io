Cloud Technology

A plug-and-play Smart Distribution Management System delivered as a cloud service.

GECE provides cloud services for its Smart Distribution Management System (SDMS) for power utilities. GECE provides the smart distribution management applications together with enterprise spatial database services and computing infrastructure. In short, the cloud service provides a plug-and-play SDMS to the power utility, complete in all respects.

This helps utilities do away with the entire procurement cycle. The power utility simply has to validate and port its data into the SDMS database, and GECE offers services for porting one-time data as part of the cloud service.

SDMS applications on the cloud

The basic SDMS architecture for power system applications is broadly classified as:

  1. Network management applications
  2. Customer management applications
  3. Real-time network operations applications

All the applications share a centralised database and integrate seamlessly to provide a true enterprise solution. All modules read from the database, process and write back results into the database, to be read and processed further by other modules.

Computing and database services

The cloud service includes enterprise spatial database services and computing server capacity for the database and the applications. The server configuration can be enhanced at any time as required by the user, either on a permanent basis or temporarily.
